# KeM Engineering Service LLC Website

Responsive multi-page Bootstrap website starter.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — Services directory
- Individual service pages: `mechanical-design.html`, `mep-engineering.html`, `3d-visualization.html`, `reverse-engineering.html`, `lifting-equipment.html`, `man-baskets.html`, `hose-baskets.html`, `custom-equipment.html`
- `portfolio.html` — Portfolio starter grid
- `blog.html` — Starter blog cards and article modal
- `contact.html` — Contact form and embedded Google Map

## Features
- Bootstrap 5.3 and Bootstrap Icons via CDN
- Logo preloader
- Horizontal scrollable services on homepage with arrow controls
- Request-a-quote modal on every page
- WhatsApp and call floating buttons
- Back-to-top button
- Responsive layout
- Google Maps embed and directions link
- Quote form prepares an email using `mailto:` (not a backend submission)

## Before publishing
1. Upload the full folder preserving its structure.
2. Ensure hosting supports HTML/CSS/JS and HTTPS.
3. Connect quote/contact forms to a real form endpoint (Formspree, Web3Forms, or your backend) if you need automatic receipt; the current version opens the visitor's email application.
4. Replace illustrative portfolio categories with real, approved project images and case studies.
5. Review all service descriptions, project claims, and technical/compliance language.
6. Confirm the embedded map location and office address.
7. Add a privacy policy and any applicable consent notices.
8. Consider configuring custom SEO titles, Open Graph images, analytics, and sitemap.

The website uses external CDNs and Google Fonts, so an internet connection is required for those assets.
